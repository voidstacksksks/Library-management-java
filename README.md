# Library-management-java
A Java-based Library Management System demonstrating Object-oriented Programming concepts through books, magazine, and library items.

## Features
- Book representation
- Magazine representation
- Library item management
- Demonstration of OOP concepts

## Technologies Used
- Java

## Object-Oriented Programming Concepts 
- Inheritance
- Encapsulation
- Polymorphism

## Project Files
- Book.java
- LibraryItem.java
- Magazine.java
- Main.java

## Purpose
This project was developed as a school exercise to practice and understand Object-Oriented Programming using Java.
